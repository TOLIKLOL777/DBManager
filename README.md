# DBManagerr

## Описание:

Сохранение информации о 10 работодателях и их вакансий с hh.ru в базе данных, а также работа с ними

## Установка:
 
1. Клонируйте репозиторий:
```
https://github.com/TOLIKLOL777/DBManager
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Создайте файл .env на основе .env.example
# Документация к модулям проекта:
### external_api.py
get_employers(): получает информацию о 10 работодателях(Vk, Яндекс, СБЕР, 2ГИС, SkyEng, Т-Банк, ЭКРА, Кейсистемс, ВТБ, HeadHunter) из API hh.ru

get_vacancies(): получает информацию о вакансиях тех же работодателей их API hh.ru

### decoder.py
employers_info(): использует ответ от get_employers() и создаёт список списков работодателей с нужными данными для работы и нужными форматом

vacancies_info(): использует ответ от get_vacancies() и создаёт список списков вакансий с нужными данными для работы и нужными форматом

### db_creator.py 
create_db(): создаёт новую базу данных используя данные из файла .env

create_tables(): создаёт таблицы для работодателей и вакансий, которые связаны друг с другом через employer_id

add_data(): добавляет данные иcпользуя формат предоставленный decoder.py в таблицы для дальнейшей работы с ними

### db_manager.py
Класс DBManager используется для произведения различных операций над таблицами

get_companies_and_vacancies_count(): Выдаёт все компании и их кол-во открытых вакансий

get_all_vacancies(): Выдаёт все вакансии с информацией

get_avg_salary(): Выдаёт среднее значение зарплаты всех вакансий у которых обозначена зарплата

get_vacancies_with_higher_salary(): Выдаёт вакансии с зарплатой выше средней

get_vacancies_with_keyword(): Производит поиск вакансий по ключевому слову

# Пример использования:
Вы запускаете файл main.py и можете выбрать 6 действий, которые хотите сделать

    1:Получить список всех работодателей и их кол-во открытых вакансий.
    2:Получить список всех доступных вакансий.
    3:Получить среднее по всем вакансиям.
    4:Получить список всех вакансий у которых зарплата выше среднего значения.
    5:Сделать поиск вакансий по заданному слову.
    6:Выход.
